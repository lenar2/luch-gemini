# Contributing to a LUCH host integration

For public user-facing text, onboarding, visuals, store descriptions and demos, use the independent [HEA Creative Release Gate](https://github.com/lenar2/luch/blob/main/docs/HEA_CREATIVE_GATE.ru.md).

Before releasing: exact-SHA non-author review, real first-impression test with five target users, visual and technical QA, and explicit founder approval. The author cannot self-certify creative excellence.

Until an administrator verifies repository rulesets, the release hold is **manual and mandatory**, not technical protection. Do not add GitHub Actions. Keep credentials, private resources and device identities out of public contributions.
