# Reporting LUCH security issues

Report vulnerabilities confidentially through [GitHub private vulnerability reporting](https://github.com/lenar2/luch-claude-plugin/security/advisories/new).

Please do not post vulnerabilities, OAuth tokens, credentials, or private user content in public issues. For general issues use [GitHub Issues](https://github.com/lenar2/luch-claude-plugin/issues/new).

The published Apache-2.0 repository is a client package; it does not include the private hosted server implementation.
